# lern_jenkiss

React + TypeScript + Vite project for learning Jenkins CI/CD.

## Features

- React 19 with TypeScript
- Vite for fast development
- Vitest for testing
- ESLint for code quality

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run test` - Run tests
- `npm run lint` - Run ESLint

## Testing

This project includes basic tests using Vitest and React Testing Library. Tests are located in `src/App.test.tsx`.
